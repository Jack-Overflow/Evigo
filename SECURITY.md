# Security policy

Security fixes target the latest release. Older releases are not maintained
separately.

## Reporting a vulnerability

Do not post vulnerability details, credentials or private deployment information
in a public issue or pull request.

Use the repository's [private vulnerability reporting page](https://github.com/Jack-Overflow/Evigo/security/advisories/new).
If private reporting is unavailable, open an issue asking for a private reporting
channel without including vulnerability details.

Include the affected Evigo version, impact, and steps to reproduce with simulated
UPS readings or other safe test inputs. Do not test against machines or UPS
equipment you do not own or have permission to use.
